# Neural Network from Scratch (NumPy)

Implementación de una red neuronal fully-connected desde cero utilizando únicamente NumPy. 

## Características 📌

- Arquitectura: 4 → 16 → 8 → 1
- Forward pass con activación ReLU
- Backpropagation completo (gradientes manuales)
- Mini-batch gradient descent
- Visualización de:
  - Arquitectura de la red
  - Evolución del loss

## Objetivo

Entender el funcionamiento interno de una red neuronal sin utilizar frameworks como PyTorch o TensorFlow.

## Resultado

El modelo logra aprender una función multivariable y reducir consistentemente el error durante el entrenamiento.
